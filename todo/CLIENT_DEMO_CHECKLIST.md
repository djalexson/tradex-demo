# Client demo checklist

Перед показом клиенту проверить:

- [ ] Лендинг открывается быстро
- [ ] Есть красивый hero с торговым терминалом
- [ ] Регистрация работает
- [ ] Вход demo trader работает
- [ ] Dashboard показывает баланс
- [ ] Есть активы BTC/ETH/EUR/AAPL/TSLA
- [ ] График TradingView открывается
- [ ] Buy order создает сделку
- [ ] Sell order создает сделку
- [ ] Баланс меняется
- [ ] Портфель меняется
- [ ] История сделок отображается
- [ ] Админка открывается
- [ ] В админке видны пользователи
- [ ] В админке можно изменить баланс
- [ ] В админке видны ордера и сделки
- [ ] Мобильная версия выглядит нормально
