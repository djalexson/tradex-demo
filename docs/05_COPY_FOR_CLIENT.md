# Текст для клиента

Предлагаю на первом этапе собрать MVP торговой платформы: лендинг, личный кабинет, котировки, графики, демо-баланс, покупка/продажа в тестовом режиме, портфель и история сделок.

Это позволит быстро показать механику будущей биржи без подключения реальных денег, брокеров, KYC и лицензий. На демо-этапе сделки будут выполняться как paper trading внутри системы, а графики и котировки можно вывести через TradingView/провайдеров данных.

После согласования концепции можно переходить ко второму этапу: реальные брокерские API, платежи, верификация пользователей, безопасность, юридическая часть и полноценная инфраструктура.

Рекомендуемый стек: Next.js + Laravel API + Filament Admin + PostgreSQL + Redis + Docker.
