# Product Scope

## Цель MVP

Показать клиенту рабочую демо-биржу с ощущением настоящей trading-платформы.

## Тип платформы

Не настоящая лицензированная биржа, а демонстрационная trading-платформа:

- котировки отображаются через виджеты/провайдеры;
- сделки выполняются внутри системы как paper trading;
- деньги виртуальные;
- пользователь видит портфель, историю, прибыль/убыток;
- админ может менять балансы, активы и настройки.

## User roles

### Guest
- видит лендинг;
- видит демо рынки;
- может перейти на регистрацию.

### Trader
- личный кабинет;
- демо-баланс;
- покупка/продажа активов;
- история ордеров;
- портфель;
- избранное;
- уведомления.

### Admin
- управление пользователями;
- управление балансами;
- управление активами;
- просмотр ордеров и сделок;
- настройка комиссий;
- блокировка пользователя;
- аудит действий.

## MVP ограничения

- Без реальных депозитов и выводов.
- Без реального исполнения ордеров на бирже.
- Без KYC интеграции, только интерфейс статусов.
- Без маржинальной торговли.
- Без плечей.
- Без настоящего matching engine.
